MOMENTUM — الظهور في جوجل وتحسين التحميل

التثبيت
1. ارفع كل محتويات المجلد إلى جذر مشروع الموقع مع الحفاظ على الأسماء والمجلدات.
   مجلد assets مهم جدًا: الصور والخطوط والسكربتات والتنسيق أصبحت داخله.
   ارفع index.html وrobots.txt وsitemap.xml وfavicon.svg وvercel.json أيضًا.
2. لا يوجد SQL جديد لهذا التحديث. إعدادات Supabase والبيانات لم تتغير.
3. بعد النشر، افتح https://momentum-fitness-nine.vercel.app/ مباشرة واختبر تسجيل الدخول والتنقل.
   ثم تحقق أن https://momentum-fitness-nine.vercel.app/sitemap.xml يفتح.

إعداد Google Search Console
1. افتح https://search.google.com/search-console/welcome بحساب جوجل الخاص بك.
2. اختر URL prefix واكتب بالضبط:
   https://momentum-fitness-nine.vercel.app/
3. أثبت ملكيتك للموقع. إذا اخترت HTML file، نزّل ملف التحقق الذي يعطيه جوجل وارفعه لجذر الموقع دون تعديل اسمه أو محتواه، ثم اضغط Verify.
   إذا اخترت HTML tag، أرسل كود التحقق ليتضاف إلى الصفحة الرئيسية. لا ترسل كلمة مرور أو كود تسجيل دخول الحساب.
4. من Sitemaps أرسل sitemap.xml.
5. من URL Inspection افحص رابط الصفحة الرئيسية واضغط Request Indexing.
Google هي التي تحدد موعد الزحف والفهرسة. الطلب لا يضمن الظهور فورًا وقد يستغرق أيامًا أو أسابيع.

ما تغير
- صفحة index.html تفتح على رابط الموقع مباشرة، مع الاحتفاظ بـtest0.html كمدخل قديم.
- عنوان ووصف واضحان بالعربية واسم MOMENTUM، canonical، بيانات المشاركة، favicon، وWebSite structured data.
- Sitemap للصفحة العامة فقط، ومنع فهرسة صفحات الحسابات باستخدام noindex.
- ضغط نفس الخلفيات إلى WebP بأحجام للموبايل والكمبيوتر، واستضافتها مع الموقع.
- الصور التي أمكن تحسينها: 4,029,608 بايت أصلية؛ نسخ الموبايل 631,138 بايت، أقل بحوالي 84.3%.
  هذا تقليل في حجم هذه الصور فقط، وليس ادعاءً أن الموقع كله أسرع بنسبة 84%.
- ملف خطوط الأيقونات وSupabase JS أصبحا محليين؛ روابط الملفات الثابتة تتغير مع المحتوى كي تُخزن في الكاش بأمان.
- نقل CSS وJS لملفات قابلة للتخزين المؤقت، وتشغيل السكربتات بـdefer مع الحفاظ على ترتيبها.
- تحميل بيانات الكابتن وتقدم اليوم في Home بالتوازي؛ أزرار البروفايل لا تنتظر هاتين القراءتين.
- تخفيف تأثيرات الخلفية الثابتة والتمويه على الموبايل أثناء التمرير.
- إصلاح رابط خلفية Unsplash كان يعيد 404. خلفية خارجية أخرى من PNGTree أعادت 403 فاحتُفظ برابطها الأصلي دون استبدال تصميمها.

التحقق
تمت مراجعة 21 صفحة عند 320 و390 و768 و1440 بكسل في متصفح Chromium ببيانات اختبار، دون أخطاء JavaScript أو تجاوز أفقي.
تمت تجربة القائمة وصور البروفايل ونسخ ID والدعوات والخروج. اختبارات PostgreSQL للتتبع والوزن والصلاحيات عدّت.
ملفات الفهرسة والعناوين والروابط المحلية وترتيب السكربتات وملف الكاش تم التحقق منها محليًا.
هذا التحديث لم يُنشر على حسابك، ولم يتم إثبات ملكية Search Console أو طلب الفهرسة نيابةً عنك.
سرعة التحميل الفعلية وCore Web Vitals تحتاج قياسًا بعد النشر على الشبكة الفعلية. استجابة Supabase نفسها تظل معتمدة على الشبكة والخادم.
